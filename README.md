# SOUGHT CONSULT - Official Website Project
Ghanaian Construction & Property Solutions
Website: www.soughtconst.com
Location: Oklemekuku Hotel, Teshei, Ghana.

## Overview
The official website for SOUGHT CONSULT, a premier Ghanaian construction and property solutions company providing civil works, building construction, fine and coarse aggregate supplies (sand and stone), sales of land, and architectural and structural drawings.

## Technology Stack
- **HTML5**: Semantic, accessible markup across all 8 official pages.
- **CSS3**: Preserved modern layout architecture with CSS Grid, Flexbox, custom design tokens, and smooth transitions. Styled in the official palette: White (`#FFFFFF`), Black (`#000000`), and Gold (`#D59E29`).
- **Vanilla JavaScript**: Zero-dependency client-side scripts managing:
  - Dual-action contact form: "SEND TO EMAIL" (`mailto:erasmuso52@yahoo.com` kept strictly internal per privacy guidelines) and "SEND TO WHATSAPP" (formatted message sent to `0268339409`).
  - Interactive FAQ accordions.
  - Responsive mobile drawer navigation with submenus.
  - Animated stat counters.
  - Consultation booking modal dialogs.

## Website Pages
1. `index.html` - Homepage (Hero, Overlapping Stat Cards, Who We Are, Services Showcase, Why Work With Us, Final CTA)
2. `about.html` - About Us (Company Description, Mission, Vision, Core Values)
3. `services.html` - Services (Dedicated cards for all 5 official services with direct enquiry actions)
4. `contact.html` - Contact (Interactive form with Send to Email and Send to WhatsApp buttons, location, phone, WhatsApp)
5. `faq.html` - Frequently Asked Questions (All 8 official Q&As in collapsible accordions)
6. `privacy.html` - Privacy Policy
7. `terms.html` - Terms and Conditions
8. `accessibility.html` - Website Accessibility Statement

## How to Run & Deploy
- Open `index.html` directly in any web browser.
- Or serve using any static hosting server (`npx serve .` or Python `python3 -m http.server 8000`).
- Ready for immediate production deployment.
